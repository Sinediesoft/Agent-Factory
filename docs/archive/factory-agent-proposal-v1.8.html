第一階段就要有的協調規則

  • 共享空間預約：軌段、等待位、工具架操作區與六台加工設備的入口各有容量 / 互斥規則。預約包含行進路徑與目的空間，不能只鎖終點。
  • 路線與占用包絡：不再鎖定兩滑台的相對次序；以路網連通、通道容量、會車條件與時間化占用包絡檢查全程。滑台、連桿、夾爪與工件一起檢查，不能只驗起點、終點或底座距離。路線受阻可改由另一方向、退讓或等待；沒有實體連通就不能放行。
  • 避免互相卡住：進入瓶頸前以原子方式取得該次通過所需的資源組；失敗就在原等待位停留。新增任務前檢查等待關係與可退出位置，發現循環等待就改序或阻擋，不以持續重試掩蓋死結。
  • 公平與優先級：任務優先級及等待時間共同決定放行；緊急插單也不能搶走已占用區域。規則需可重現，防止同一手臂長期無法取得資源。
  • 逾時與故障：移動逾時、回報延遲或手臂停機時，保留實際占用及不確定區域；不能單靠預約到期就當作路徑已清空。另一台只能執行經確認不受影響的任務。
  • 畫面與執行一致：兩台手臂各有狀態機 / 佇列，使用共同事件時鐘；R1 / R2、4 台 CNC、EDM-01、WIRE-01、軌段占用與工具架預約分列時間軸，等待原因可追溯到資源與持有者。

1. 發佈任務與排程使用者指定產品、件數與交期；Agent 顯示需求、產品路由版本、所選加工設備 / 工具、甘特圖與預計完工時間。六台設備在場景中可見，但依路由選用必要站點。缺少工藝 / 節拍 / 能力時提示資料不足；可行計畫須包含雙臂、換爪、轉運、等待、裝卸與區域占用。合成示範路由必須明確標記。
2. 選爪與換爪R1 / R2 各自從待機位接單，高亮目標夾爪與槽位；取得通行及工具架預約後到站，需要換爪時先放回原工具再取新工具，顯示工具 ID 與確認狀態。先安置持有工件；確認原工具可放回、目標工具可用、介面相容及工具已鎖定。模擬使用對應事件；實機以真實回覆判定。
3. 取毛胚 / 在製品與上料手臂依已驗證路徑抵達所選 CNC、EDM-01 或 WIRE-01，呈現旋轉、夾取、搬運、設備門 / 工作槽狀態與治具定位。後續工序搬運同一工件 ID 的在製品。確認抓取、裝卸許可、門 / 槽及區域狀態；治具夾持確認後才釋放。放電電極、線割加工線及各站特有前提依模組規格檢查。
4. 退出、設備就緒與加工手臂退出；CNC 呈現關門與加工，放電呈現電極 / 工作槽與進度，線割呈現加工線 / 工作槽與進度；外觀變化為示意。設備專屬前提通過才執行既有配方。不同工序依路由銜接，S-C 完成後才可進 S-D；不包含自動產生 CNC / 放電 / 線割加工程式或驗證加工品質。
5. 工序完成與下料 / 轉運接收所選設備的完成事件，等待允許裝卸；手臂取出工件並送往下一合格站或緩衝區。完成全部必要工序後才送成品區。完成事件與裝卸條件分開確認；依夾持 / 治具交握取件、到站確認更新位置。需要換爪時先安排，單站完成不直接當作整件完工。
6. 再上新料與結案依實際取料扣減毛胚；僅在全部必要工序與成品放置確認後增加成品數。返回取料環節，讓觀眾看見完整連續循環。剩餘件數大於零才繼續；相容工具可沿用。工單完成依實際模擬事件累計，不靠畫面計時器單獨宣告。
7. 異常分支工具缺失、鎖定逾時、門 / 槽未到位、治具未夾緊、放電電極未就緒、線割加工線未就緒 / 斷線、任一設備停機或路徑衝突時，顯示原因與受影響任務。保留已完成事實與不可任意中斷的加工；尚未開始工序可重排，移動中的路徑依共同驗證結果改道 / 退讓 / 等待。Unknown 先對帳，禁止無條件重播取放、換爪或啟動。

第一階段 / 混合製程配置兩台方案 1 同能力平行加工；另外兩台方案 2 不同工序依序流轉。另在明確標示的組間串接情境中測試完整流轉。平行組每件擇一且可並行處理不同件；串聯組禁止跳站與前序未完成即啟動。機台 ID 對應、工件追蹤、轉運和最終完工計數與所選路由一致。
第一階段 / 動態指派對相同工序改變 R1 / R2 位置、已裝工具、合格加工設備可用時間或路徑占用，建立至少一組候選排序改變的案例。只在可行候選中重選手臂 / 加工設備，能說明選擇原因；能在已建模的通路與區域條件允許的不同情境下改變指派，不固定依機台 ID 綁定手臂。允許經合格替代路線改變相對位置，不能穿越實體占用或重複執行任務。
第一階段 / 區域競爭與阻塞兩臂競爭共享軌段、工具、工具架或各加工設備入口；測試對向來車、會車點占用、繞行路線受阻與循環等待。遵守通道容量與時間化包絡；無有效路線則顯示等待 / 受阻，不能穿越或瞬移。能解開的循環等待依規則改序；不能解開則明確阻擋。
第一階段 / 另一方向抵達封鎖一條接近路線，保留另一條已建模且無衝突的路線；再將兩條都封鎖。前者改由另一方向抵達且保留選路理由；後者不出發。任務接單、路徑驗證、預約與移動事件順序一致。
第一階段 / 動態避讓R1 在允許中斷的作業階段占用 R2 路線；另測 R1 正在不可中斷的夾持交接、兩臂同時重規劃與舊狀態延遲回報。可退讓時生成共同驗證的新路徑並更新甘特圖；不可退讓時 R2 等待。模型中的掃掠包絡無交集，過期版本不放行；不出現雙方反覆改道的活鎖。
第一階段 / 故障與復原一台手臂在共享區域內停機或失去位置回報，之後恢復。保留占用 / 不確定區域，阻擋相依路線；另一台僅在確認不受影響的區域執行。復原先對帳位置、工件、工具與預約，再重新派工。
第二階段 / 動作驗證建立已標註的可達 / 不可達、無碰撞 / 有碰撞、超出關節限制、更換大尺寸夾爪後碰撞、雙臂同時伸入 / 滑台移動 / 停止姿態、放電 / 線割工作槽開合與裝卸干涉案例。在版本固定的模型上得到預期分類；六台加工設備、兩臂、滑台、夾爪與持有工件都包含在檢查中；對應同一時間序列，模型資料不足不得回傳「已驗證可行」。
第二階段 / 校正與追溯修改 TCP、工具架位置或設備模型版本後重驗；保存輸入、模型、路徑與結果。舊驗證被標記失效，重新驗證後才能發佈對應計畫；真機座標容差與試跑標準另依選用設備共同訂定。

      在同一主資料快照下比較原計畫與候選計畫，輸出準交率、在製品、瓶頸、等待與故障風險。

      核准綁定計畫雜湊與資料版本。派工前再查料況、設備、治具、操作員與配方版本；變動超出容許範圍則回到規劃。

    5. 實績 → 偏差偵測 → 滾動重排

      對未開始工序重排，保留已完成事實與正在加工的承諾；運動路徑變更由協調服務在可中斷點處理，不能以重排跳過夾持交接。重排加入變動成本，避免工單反覆跳動。

      結果不明就標記 Unknown / AwaitingReconciliation，查設備與工單狀態後再決定。可能重複啟動的命令不盲目重送。

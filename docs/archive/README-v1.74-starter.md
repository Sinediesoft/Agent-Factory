# Agent Factory

工廠 Agent 排程與模組化產線模擬平台。

目前版本包含 **v1.74 HTML 企劃書**與可離線操作的 **2D 排程基準 Demo**。七設備 3D 工作站、雙臂運動、工具更換、動態避讓、有限槽位緩衝、手動補料 / 移走成品控制、真正的 LLM Agent 與實機介接尚未實作。

## Codex 實作入口

請先讀取 [CODEX_HANDOFF.md](CODEX_HANDOFF.md)。桌面 `Agent Factory` 在交接前只有 v1.8 舊企劃書；本包 `factory-agent-proposal.html` 與 `index.html` 為 v1.74。切換工作目錄、備份舊版並同步最新資料後開始實作；本包未包含新 3D Demo，亦未代表 GitHub 已同步。

## MVP 收斂與剩餘問答

以「能合理開始第一版 Demo 開發」為準，目前剩餘必答 Grill Me 為 **0 題**。既定產品、七設備、雙臂、六件流程、工具 / 槽位、軌道及基本 3D 編輯保留；工程自行提出可調示範尺寸、非加工時間、初始配置與技術選型並驗證，不再逐一詢問。實機工藝、品牌型號、校正及 Adapter 留待導入階段；必要外部帳號 / 憑證於實際串接時處理。這表示規格足以開工，不表示 3D Demo 已完成，文件中的待設計項目仍須落實。

先跑通預設場景六件端到端流程，再補齊已確認的基本編輯與異常驗收；開發替身不得冒充真實 LLM。只有需求衝突、必須改變產品範圍或缺少使用者專有必要資料時，再集中詢問。

## 開啟企劃書與 Demo

下載此儲存庫後，用瀏覽器開啟 [`index.html`](index.html)，無須安裝套件或啟動後端。章節 00 列出最新規格與實作狀態，章節 02 是既有可操作 Demo。

GitHub 檔案頁顯示 HTML 原始碼；下載至電腦後開啟即可互動。本儲存庫尚未設定 GitHub Pages。

## 目前可操作的功能

- 修改合成訂單件數、交期，以及 EDD / SPT / FIFO 排程策略。
- 加入平行 CNC 或檢測資源，觀察完工時間變化。
- 插入急單、注入 CNC 停機，重排尚未開始的工序。
- 查看甘特圖、完成量、交期風險、事件紀錄與時間回放。
- 停用必要工序，驗證不可行排程會阻擋模擬。

既有 Demo 的流程是「加工 → 檢測 → 包裝」，資料皆為合成值。它不代表最新七設備產線，也未連接 LLM、OR-Tools、MES 或真實機台。
